# Roomly agent instructions

When implementing, redesigning, testing, or deploying Roomly, read `ASTRA_IMPLEMENTATION_HANDOVER.md` completely before making changes. It is the decision-complete source of truth for the current end-to-end release, including Roomly Home, manager and resident onboarding, AI behaviour, security, sequencing, and acceptance criteria.

Preserve `index.html` as a prototype reference by moving it to `docs/prototypes/roomly-pass.html` during the application scaffold. Do not treat its hard-coded content or simulated success messages as production behaviour.
